# Настройка бота в BotFather

Откройте @BotFather в Telegram и настройте следующие параметры для вашего бота:

## 1. Основная информация

### /setname
**Имя бота:** `Теннис Корт 40`

### /setdescription
**Описание бота (до 512 символов):**
```
🎾 Бот для уведомления о свободных слотах на теннисных кортах kort40.online

Показывает доступное время с прогнозом погоды для Калуги. Отправляет уведомления при появлении новых слотов.

Просто отправьте /start чтобы начать!
```

### /setabouttext
**О боте (до 120 символов):**
```
Уведомления о свободных слотах для теннисных кортов kort40.online с прогнозом погоды для сквера Волкова в Калуге 🎾```

## 2. Изображения

### /setuserpic
Установите аватар бота (фото теннисного мяча или корта)

## 3. Команды бота

### /setcommands
```
start - 🏁 Начать работу с ботом
slots - 📅 Выбрать период для просмотра слотов
slots_week - 📅 Слоты на неделю
slots_two_weeks - 📅 Слоты на две недели
slots_month - 📅 Слоты на месяц
help - ❓ Помощь
```

## 4. Настройки меню

### /setmenubutton
Настройте кнопку меню для быстрого доступа к командам

## 5. Дополнительные настройки

### /setjoingroups
`Disable` - бот работает только в личных сообщениях

### /setprivacy
`Disable` - бот не читает все сообщения в группах (если добавлен)

### /setinline
`Disable` - инлайн режим не используется

### /setlanguage
`Russian` - основной язык бота

## 6. Команды для администратора

### /mybots
Управление всеми вашими ботами

### /token
Получить новый токен (если нужно)

### /revoke
Отозвать токен бота (в случае компрометации)

## 7. Дополнительные улучшения

### Suggested Actions (через Bot Settings)
- Добавьте подсказки для новых пользователей
- Настройте приветственное сообщение

### Bot Language
Установите `ru` чтобы Telegram не предлагал перевод

## Пример настройки команд в BotFather:

1. Отправьте `/mybots`
2. Выберите вашего бота
3. Нажмите `Edit Bot`
4. Выберите `Edit Commands`
5. Отправьте список команд из пункта 3

## Проверка настроек

После настройки проверьте:
- [ ] Имя бота отображается корректно
- [ ] Описание видно при добавлении бота
- [ ] Команды появляются в меню
- [ ] Аватар установлен
- [ ] Язык установлен на русский
